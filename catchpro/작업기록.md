# CatchPro 작업기록

## 2026-04-23

### 오늘 정리한 방향
- 앱 목적을 아래 3가지로 명확히 정리함
  - 도착지 / 상차지 거리 / 요금 3조건이 맞는 오더 자동확정
  - 메인 오더를 수행하면서 비슷한 목적지의 추가 오더 자동확정
  - 비슷한 목적지의 다건 배송을 짧은 시간 안에 처리

### 오늘 구현한 주요 내용
- 인성 상세 화면에서 `수행중 저장` 오버레이 버튼으로 현재 메인 오더 목적지를 저장하는 기능 추가
- 자동으로 잡은 오더를 사용자가 `취소`했을 때 `auto-cancelled`로 기록하고, 같은 오더를 90초 동안 다시 자동확정하지 않도록 처리
- 관찰 로그 export에 상태값, 화면 모드, 확정/취소 버튼 정보까지 같이 저장되도록 확장
- UI 구조를 목적 기준으로 재정리
  - `대시보드`: 운영 목표와 현재 자동확정 기준 요약
  - `오더 조건`: 도착지 / 상차거리 / 요금 / 메인 목적지 반경 조건 관리
  - `목적지`: 자주 가는 배송 축, 대표 주소, 권역 관리
  - `설정`: 접근성, 알림, 패키지 필터, 로그 보관 같은 시스템 설정만 유지
- `전국 지역에서 선택` 기능을 오더 조건과 목적지 화면 양쪽에 붙임
- 전국 지역 선택과 도착지 매칭을 더 보수적으로 개편
  - `서울 강남구` 같은 축약형 대신 `서울특별시 강남구` 같은 정식 행정구역 경로를 내부 기준으로 사용
  - 예전에 저장된 축약형 지역도 새 기준으로 자동 읽기
  - `1차 자동오더`와 전국 선택 다이얼로그에 `서울특별시 강남구 전체` 같은 명시적 권역 문구 표시
  - 도착지 매칭 시 `시/도 + 시/군/구`가 함께 맞아야 행정구역 매칭으로 인정하도록 규칙 강화
- 행안부 공식 주소코드(`jscode20250113.zip`)를 내려받아 전국 `동/읍/면` 데이터 생성
  - `KoreaAdministrativeTownData.kt` 생성
  - 전국 선택 화면을 `시/도 -> 시/군/구 -> 동/읍/면` 3단계 선택기로 개편
  - `구 전체 선택`과 `개별 동 선택`을 함께 지원
  - `서울특별시 강남구 전체`를 고르면 하위 동 목록이 다이얼로그와 1차 자동오더 요약 카드에 같이 보이도록 개선

### 현재 사용 흐름
1. 인성 상세 화면에서 메인 오더를 열고 `수행중 저장`
2. `오더 조건` 화면에서
   - 도착지 조건
   - 상차지 거리 조건
   - 최소 요금 조건
   - 메인 오더 목적지 반경
   을 설정
3. 추가 오더 상세 화면 진입
4. 조건이 모두 맞으면 CatchPro가 자동으로 `확정`

### 현재 기준 주요 화면
- 대시보드
- 목적지
- 오더 조건
- 이력
- 설정

## 2026-04-24

### 실행 로그 분석 결과
- 오늘 로그에서 `리스트 OCR -> 조건 후보 행 자동 클릭` 흐름이 실제 문제 원인으로 확인됨
- OCR이 도착지 후보를 맞게 잡아도, 인성 리스트가 갱신되거나 클릭 좌표가 어긋나면 다른 오더 상세가 열릴 수 있었음
- 상세 화면 재검증은 작은 확인창/확정은 막을 수 있지만, 이미 잘못 열린 오더 상세 화면 자체를 막지는 못했음
- 휴대폰 내부 DB 기준 오늘 이력은 `active-drive-synced` 17건, `active-drive-manual-sync` 6건, `manual-review` 1건으로 확인됨
- ADB `CatchProOCR` 로그 버퍼는 설치 후 비어 있었고, 시스템 로그에는 앱 재설치/접근성 서비스 실행 로그만 확인됨

### 반영한 개선
- 1차 자동오더에서 리스트 OCR 자동 클릭 경로를 제거
- 사용자가 인성 리스트에서 오더를 직접 누른 뒤, 열린 상세 화면에서만 도착지 / 상차거리 / 요금 조건을 판정하도록 변경
- `list-ocr` 런타임 로그, OCR 스크린샷 처리, 미사용 OCR 파서 파일, ML Kit OCR 의존성을 제거
- 1차 자동오더 화면, 대시보드, 사용설명서, 계획서 문구를 상세 화면 기준 흐름으로 정리
- 이력 화면에서 `active-drive-manual-sync`가 영문 상태로 보이지 않도록 `메인오더 수동저장` 한글 라벨과 사유 문구를 추가
- 전국 지역 선택에서 `지역 추가` 버튼으로 여러 시·군·구/동을 한 번에 이어 선택할 수 있게 개선
- 인성 도착지 텍스트가 `시/군/구 / 동/읍/면 / 고객명` 형태일 때 `시/군/구 + 동/읍/면`을 함께 저장하도록 파서 개선
- `메인오더 자동연동`과 `메인오더 수동저장` 이력을 화면에 보이도록 정리하고, `확인 대기` 라벨을 `수동확인 알림`으로 변경
- 메인오더 자동연동/수동저장도 TMAP 연결 대기열에 등록되도록 개선
- 2차 자동오더 화면에서 자동 등록된 메인오더 목적지 주소를 여러 줄 전체 주소로 표시
